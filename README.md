# Projeto Integrador: Computação Científica 💻

Repositório destinado aos Exercícios-Programa (EPs) desenvolvidos para a disciplina de Computação Científica.
**Integrantes:** Gustavo Souza Freitas, Miguel Hakira Mendes Kato e Gabriel Martins.

## Projetos Desenvolvidos

* [**EP1 - Cálculo da Série de Taylor**](./EP1_Serie_de_Taylor/): Algoritmo numérico linear $O(N)$ para aproximação polinomial da função $y = \sin(x^2)$ implementado em Python.
* [**EP2 - Simulação de Eventos Discretos**](./EP2_Simulacao_Discreta/): Modelagem estocástica com SimPy para análise de fluxos e gargalos em um sistema de bicicletas compartilhadas.
